Place three short audio files here:

  beep.mp3   - a short, sharp beep (default)
  chime.mp3  - a gentle chime
  gong.mp3   - a deeper gong sound

Recommended length: 1-3 seconds. Royalty-free sources:
  - https://pixabay.com/sound-effects/
  - https://freesound.org/

If a file is missing, the app falls back to vibration only without crashing.
